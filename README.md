# Pack Menuiserie Rentable — Métier Utile

Page de vente statique (HTML / CSS / JavaScript, sans dépendance) pour le pack
**Menuiserie Rentable**.

## Contenu
- `index.html` — la page complète
- `images/` — visuels (hero, réalisations, témoignages, vignette de partage)
- `favicon.png`

## Fonctionnalités
- Compte à rebours promotionnel (boucle de 32 h)
- Timeline animée « Ça te parle ? » (responsive)
- FAQ accordéon
- Notifications d'achat qui défilent
- Barre d'appel à l'action collante
- Bouton WhatsApp flottant (message pré-rempli)
- Suivi Meta Pixel (PageView, InitiateCheckout, Contact)
- Images optimisées pour un chargement rapide sur mobile
- Balises Open Graph / Twitter pour le partage (vignette)

## Publication
Site statique : hébergeable tel quel (GitHub Pages, Vercel, Netlify…).
